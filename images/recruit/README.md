# images/recruit/ フォルダについて

「学祭Techフェス・応募企画」ページ（recruit.html）で使う企画写真を置くフォルダです。

## 使い方

1. 企画の写真をこのフォルダに追加する（例: `denshi-kousaku.jpg`）
2. `js/recruit.json` の該当する企画の `img` にファイル名だけを書く（拡張子込み・パス不要）

```json
{
  "img": "denshi-kousaku.jpg"
}
```

## ポイント

- 対応する拡張子: `png` / `jpg` / `jpeg` / `webp` / `gif`
- ファイル名は半角英数字・ハイフン・アンダースコアのみ（日本語ファイル名は表示されません）
- 画像が見つからない場合は自動的に技科大祭ロゴ（`images/TUTFESlogo.png`）に切り替わります
- 写真は横長（16:10くらい）が一番きれいに収まります。あまり重い画像は避けてください（1MB以下推奨）
